---

界面换了一套，深浅主题都能跟系统走；操作路径重新捋了一遍，生成过程可见、可取消，
生成完能直接打开文件；顺带把上游 edge-tts 从 7.0.0 升到了 7.3.1。

## 你会看到什么不同

- **深浅主题**：跟随系统，也可以在标题栏一键切到固定浅色或深色。标题栏、滚动条、
  下拉列表一起变，不会留一条白带。**设置窗口与使用提示也跟着主题变。**
- **界面干净了**：整个面板只有一个底色，不再是一块一块的色块；所有可点击的按钮
  **都是圆角**，共用同一套外观（浅底 + 描边），一眼能看出哪里能点。
  「生成语音」还是那只蓝按钮。
- **窗口更大**：默认窗口加宽了一半、加高了一成，编辑区长得多。
- **`F1` 去掉了**：它和很多程序的常用热键冲突。看提示请点右上角的「?」或按 `Ctrl+H`。
- **生成过程看得见**：不再是一条来回跑的进度条，而是"已生成多少秒音频、已接收多少字节"。
  旁边有「取消」——**取消之后不会留下半截文件**。
- **生成完能直接用**：状态栏给出音频与字幕的完整路径和大小，并有「打开音频」
  「所在文件夹」两个按钮。不再弹一个挡住一切的「成功」对话框。
- **语音好找了**：322 个语音的列表多了一个筛选框。输入 `en 女`、`zh-CN`、`晓晓`
  都能过滤。
- **使用提示**：第一次运行有一条三步提示；编辑区下方常年显示快捷键；点右上角的「?」
  打开完整说明（含常见问题）。
- **可以读入 / 另存文本**：`Ctrl+O` 读入 `.txt` / `.md` / `.srt`（UTF-8 读不了时
  自动试 GBK），`Ctrl+S` 另存。
- **语速 / 音量 / 音调**有了输入框，旁边实时显示"原声"或"语速 +20%"。
- **设置窗口**：主题、默认输出目录、网络代理、提示开关。改完立即生效。
- **记住你的偏好**：上次用的语音、参数、输出目录、文件名。

## 修掉的两个老问题

- **同一段文字，下拉框显示的声音和实际用的可能不是同一个。**
  旧代码用语音的 `Name` 建列表、用 `ShortName` 显示，而这两个字段的排序结果不一样。
  现在全程只用一个字段。
- **粘贴文字之后点生成，有时会说"编辑区是空的"。**
  输入框里那句占位提示不是真的占位，它是普通文本；粘贴的内容会和它混在一起，
  于是校验认为你没写东西。现在占位提示在你开始输入的一瞬间就消失，不会混进来。

## 上游同步

edge-tts 从 **7.0.0 升到 7.3.1**。7.3.x 起上游自带字幕合成（不再需要 `srt` 包），
调用接口与输出格式都核对过：字幕文件的格式与上游逐块一致。

## 怎么升级

到下面的 Assets 下载 `GUI-of-Edge-TTS.exe` 覆盖旧的就行，免安装。
设置会自动沿用（存在 `%APPDATA%\GUI-of-Edge-TTS\settings.json`）。

`--version` 现在会打印形如 `Edge-TTS 1.1.0+<提交>`，`+` 后面是构建它的提交。

## 已知限制

- **必须联网**：语音由微软的在线服务合成。
- **中文标点会被换成英文标点**再送给上游（上游对全角标点的断句质量更差），
  所以字幕里是英文标点。
- **按钮不是真圆角**：Tk 画不出圆角，这一版用"1 像素描边 + 留白"代替。
  这是取舍，不是做不到。
- **保存／打开文件的那个对话框**内部跟随系统主题，不跟随本程序的深浅开关
  （标题栏会跟着变）。
- **一次生成一份音频**，没有批量队列。
